      How to use

      1. Add a class. Click Add class on the left and give it a name, such as Grade 8B.
      2. Add students. Paste your class list (numbered or not) or type names one by one and press Enter.
      3. Choose the subject. Pick the MYP subject group and type the course name used in comments, such as Physics. Click Unit and concepts to add the unit, global context, key concepts and related concepts.
      4. Enter marks. Type criteria marks (0 to 8) on each row, or click Paste marks and paste from Excel. The final grade is worked out for you.
      5. Set student options. Use Set for whole class to give everyone a starting level in one click. Then click a student’s name to change their engagement, behaviour, progress, attendance, academic integrity, strengths, learner profile and ATL skills.
      6. Write comments. Choose a comment length at the top, then click Write all comments. Templates work offline. AI chatbot mode gives you a prompt to paste into Gemini, ChatGPT or Claude, then you paste the reply back.
      7. Check and send. Read and edit each comment, then copy it or use Export to move comments into ManageBac, Toddle or your school’s system.
      8. Keep a backup. Everything saves on this computer automatically. Use Save backup to keep a copy or move to another PC.

      Clear comments

      This removes written comments only. Students, marks and options stay. It can’t be undone, so save a backup first if you might need them.

      Export comments

      Works with ManageBac, Toddle, Sana, PowerSchool, Veracross, iSAMS, Engage and other reporting systems. Most systems let you paste each comment into the student’s report, so open the Excel file beside the system and copy across. If your school imports comments in bulk, send the Excel file to your coordinator.
